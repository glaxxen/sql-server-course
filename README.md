# SQL Server Course for Absolute Beginners

A hands-on course by **Past Hundred** for anyone learning SQL from scratch. Start by setting up Microsoft SQL Server and SQL Server Management Studio (SSMS), then use the numbered scripts to practice writing queries.

## What you'll learn

- Retrieve, filter, and sort data with `SELECT`, `WHERE`, and `ORDER BY`.
- Work with temporary tables, handle `NULL`, and add or update records.
- Summarize data with `GROUP BY`, aggregate functions, and `HAVING`.
- Combine data using joins, `UNION`, and `UNION ALL`.

## How to follow along

1. Install Microsoft SQL Server and SQL Server Management Studio (SSMS).
2. Download the scripts using **Code → Download ZIP**.
3. Open `01. Intro to SQL.sql` in SSMS and follow the scripts in numerical order.

Use a practice database for scripts that update or delete data.
